## 正文

```
[插件] AutoMountLite —— 自动上坐骑，零依赖，自带设置面板

=== 这插件干嘛的 ===
你一动、且没在干别的事，就自动上坐骑。
功能灵感来自 Dugi Questing Essential 的「自动上坐骑」模块，但这是独立实现，
不含 Dugi 任何代码，就一个 lua 文件，不依赖任何库。

=== 特性 ===
· 配置在「选项 → 插件 → AutoMountLite」里鼠标点，不用记命令
· **中英双语界面**：默认跟随客户端，也可手动切换（/am lang zhCN|enUS），
  聊天输出、面板文字、键位描述全部本地化
· 两种模式：
  - 随机偏好（默认）：调用 SummonByID(0)，和你在坐骑图鉴点「随机召唤偏好坐骑」
    是同一个调用，只会召唤你标了星星的坐骑
  - 环境内最快：按当前环境（地面/飞行/御空/水下）的速度权重挑
· 可以按环境分别指定坐骑：地面一只、飞行一只、水下一只，也能设成「不骑」
  （比如只想骑凤凰：/am mode fastest 然后 /am pref flying 183）
· 施法后延迟可调（0–10 秒，默认 1 秒）
· ALT+Z 开关（可在按键设置里改）
· /am diag 一键诊断：当前区域哪些收藏能用、权重最高的是哪几只

=== 安全声明 ===
只调用暴雪官方 API（C_Timer / C_MountJournal）。
不模拟按键、不注入、不 hook、不联网。单文件，源码可查。
MIT 开源，仓库：https://cnb.cool/wuhuarou-2026_799/wow-addons

=== 下载 ===
CNB Release：https://cnb.cool/wuhuarou-2026_799/wow-addons/-/releases
（解压出 AutoMountLite 文件夹，丢进 _retail_\Interface\AddOns\，重启游戏）

=== 已知问题 / 反馈 ===
· 12.x 客户端实测可用；如果你遇到不召唤，先输入 /am diag 把输出贴出来
· 想要什么功能（比如按专精换坐骑、战斗中不召唤的白名单）欢迎回帖
```

## 回复模板（有人问「和 Dugi 冲突吗」）

```
不冲突，但建议只开一个，否则会重复召唤。
Dugi 那边关掉：/dugi automountoff
本插件关掉：/am off
```

## 回复模板（有人问「为什么只召那几只」）

```
默认 random 模式只从你标了星星的收藏里随机（暴雪 API 语义）。
想改：去坐骑图鉴增删收藏，或者 /am mode fastest 切到「环境内最快」，
再用 /am pref <ground|flying|aquatic> <坐骑ID> 精确指定。
/am favs 能列出你收藏的坐骑和它们的 ID。
```
